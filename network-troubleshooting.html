WRITE-UP 01

Troubleshooting Network Connectivity

A practical troubleshooting exercise focused on diagnosing connectivity problems between systems and identifying configuration issues affecting network communication.

Networking OPNsense Linux Troubleshooting
01

The Problem

The lab environment contained multiple virtual machines connected through an OPNsense firewall. The systems were configured on a private network, but communication between a client and the firewall interface was not working as expected.

The objective was to determine where connectivity was failing and identify the configuration that prevented the systems from communicating correctly.

02

Lab Environment

OPNsense

Used as the firewall and network gateway responsible for routing traffic between configured interfaces.

Kali Linux

Used as the client system for testing connectivity and performing network troubleshooting.

VirtualBox

Provided the virtualized environment in which the firewall and client systems were configured.

Private Network

A dedicated private network was used to allow the virtual machines to communicate through the firewall.

04

Investigation

The first step was to verify the network interfaces and IP addresses assigned to each virtual machine.

Connectivity tests were then performed between the client and the OPNsense interface. The results showed that the client could communicate with some systems but could not reach the expected firewall interface.

This narrowed the investigation toward interface configuration, addressing and virtual network connectivity rather than the application layer.

05

Resolution

Configuration Verification

The virtual network configuration and interface assignments were reviewed and corrected where necessary.


Connectivity was then tested again to verify that the client could communicate with the expected network interface.

06

Key Takeaways

Network troubleshooting should begin with the fundamentals: interfaces, addressing, routing and connectivity.

Testing connectivity step by step makes it easier to isolate the layer at which a problem is occurring instead of changing multiple configurations at once.

This exercise reinforced the importance of understanding how virtual network adapters, firewall interfaces and IP addressing work together in a lab environment.
