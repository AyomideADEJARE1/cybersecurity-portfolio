A hands-on Azure security lab covering Microsoft Entra ID, group-based RBAC, least privilege, Azure Storage, Azure Policy, and security configuration remediation.

A Python-based network monitoring tool that checks device availability, measures latency, tests TCP ports, classifies network health, generates alerts, and records monitoring results.
